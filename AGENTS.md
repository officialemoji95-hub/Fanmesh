# FanMesh contributor guide

## Product principle

FanMesh helps creators build consented, creator-owned audience relationships. Do not add scraping, credential capture, fake engagement, rate-limit bypasses, unsolicited bulk messaging, or attempts to manipulate platform ranking systems.

## Working agreements

- Keep scoring and recommendations explainable.
- Use official APIs, user-provided exports, and webhooks only when the creator is authorized to access the data.
- Collect the minimum data required and preserve consent provenance.
- Run `npm test` and `npm run check` before publishing changes.
- Keep the zero-dependency prototype runnable on Node.js 20+.
